# Windows 音频验证矩阵

每个发布候选至少覆盖以下组合。自动化测试不能替代真实设备验证。

| 场景 | 麦克风 | 系统声音 | 预期结果 |
| --- | --- | --- | --- |
| 仅本人发言 | 开 | 关 | 麦克风录音与实时转写正常 |
| 仅远端会议 | 关 | 开 | 系统声音录音与实时转写正常 |
| 双路会议 | 开 | 开 | 混音录音连续，两路内容均可辨认 |
| 系统声静音 | 开 | 开 | 显示非致命告警，麦克风录音继续 |
| 麦克风不可用 | 开 | 开 | 显示非致命告警，系统声音录音继续 |
| Provider 未配置 | 开 | 开 | 录音正常，转写标记为待重试 |
| Provider 中途断网 | 开 | 开 | 录音正常，实时转写降级，会后可重试 |
| 暂停后恢复 | 开 | 开 | 同一会议、同一文件继续写入，不归档 |
| 结束后立即新建 | 开 | 开 | 两个会议数据、任务和事件不串线 |
| 异常退出后重启 | 开 | 开 | 未完成会议可见，已落盘录音不丢失 |

建议至少在以下环境各执行一次：

- Windows 11 内置声卡与有线耳机；
- Windows 11 蓝牙耳机；
- Windows 10 或干净 Windows 虚拟机；
- 没有系统声音播放的静音桌面；
- 企业代理或短时断网环境。

记录设备名称、系统版本、应用版本、测试时长和失败日志。不要把真实会议录音、API Key、数据库或日志提交到 Git。
