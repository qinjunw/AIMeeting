# 作品边界

更完整的公开版定位、验证路径、隐私和使用边界见 [作品集公开版说明](PORTFOLIO_EDITION.md)。

## Supported

- DashScope 麦克风流式 ASR
- interim/final 转写和中文规范化
- 手工转写测试入口
- 配置外部 Agent Provider 后的增量纪要和基于会议证据的问答
- 本地会议历史

## Experimental

- 文本唤醒后的自动 Copilot 工作流
- 可配置的外部搜索 endpoint
- Tauri 桌面安装包

## Out of scope

- 系统声/扬声器 WASAPI loopback
- 自动说话人识别或声纹识别
- 离线 ASR 和任意云 ASR Provider
- 加密存储、多用户权限和企业合规审计
- 声称搜索计划记录等同于真实联网搜索结果

## 展示素材说明

截图和视频可能展示完整本地原型中的 System probe、系统声或混合来源统计。这些画面不代表当前公开源码包含对应捕获实现。
