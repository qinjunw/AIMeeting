# 作品边界

## Supported

- DashScope 麦克风流式 ASR
- interim/final 转写和中文规范化
- 手工转写测试入口
- 增量纪要和基于会议证据的问答
- 本地会议历史

## Experimental

- 文本唤醒后的自动 Copilot 工作流
- 可配置的外部搜索 endpoint
- Tauri 桌面安装包

## Out of scope

- 系统声/扬声器 WASAPI loopback
- 自动说话人识别或声纹识别
- 离线 ASR 和任意云 ASR Provider
- 加密存储、多用户权限和企业合规审计
- 声称搜索计划记录等同于真实联网搜索结果
