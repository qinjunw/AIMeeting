# 演示脚本

建议准备两版视频：60 秒无 Key 演示和 90 秒真实 ASR 演示。

## 无 Key 演示

1. 打开一个空会议。
2. 用手工转写输入三段会议发言。
3. 展示实时摘要和行动项更新。
4. 输入唤醒短语与问题，展示证据化回答或无模型时的明确降级提示。
5. 停止会议并打开历史记录。

## 真实 ASR 演示

1. 在录屏外完成 Key 配置。
2. 启动麦克风，朗读预先准备的公开会议稿。
3. 展示 interim 到 final 的变化和中文规范化。
4. 触发摘要与 Copilot。

不要在视频中显示 Key、真实会议内容、浏览器存储或通知中的个人信息。
