# 演示脚本

建议准备两版视频：60 秒无 Key 的公开仓库验证和 90 秒真实 ASR/Agent 演示。

## 无 Key 演示

1. 打开一个空会议。
2. 用手工转写输入两段普通会议发言，展示 Raw ASR segments 和麦克风来源计数。
3. 输入 `嗨助手 总结刚才内容`，展示文本唤醒和 Copilot 问题捕获。
4. 展示未配置 Agent Provider 时纪要和提问入口的明确提示，不展示伪造的摘要或回答。
5. 停止会议并打开本地历史记录。

## 真实 ASR 演示

1. 在录屏外完成 DashScope ASR 与 Agent Provider 的 Key 配置。
2. 启动麦克风，朗读预先准备的公开会议稿。
3. 展示 interim 到 final 的变化和中文规范化。
4. 展示外部文本模型生成的递增纪要，再触发 Copilot 并展开会议证据。

不要在视频中显示 Key、真实会议内容、浏览器存储或通知中的个人信息。
